# $bog_gamengine_net_pair

Парный сценарий сети: два окна на одной комнате, движение героя первого видно второму быстрее
чем за 200 мс. Лежит отдельным модулем и **в списке `modules:` рабочего потока не стоит.**

## Почему не в CI

Сценарию нужен мастер Гипер Базы на 9090, а на раннере его нет. Оставить проверку в прогоне
нельзя: её пропуск («мастер Базы на 9090 не слушает») сошёл бы за успех, и CI отчитывался бы о
проверке сети, не сделав её. Вечно красной делать тоже нельзя — `$mol_test` встаёт на первом
падении, и постоянный красный заслонил бы любой настоящий после себя.

Пропуск здесь **недостающего условия**, а не непреодолимого: мастера можно поднять. Поэтому из
прогона убрано обещание, а не проверка целиком.

Проверяемая половина осталась в прогоне: `$bog_gamengine_net_probe_alone` поднимает одно окно с
`master=` в адресе и утверждает, что оно объявило комнату и увело героя вправо по D. Мастера ей
не нужно — замерено 25.09.2026: без мастера окно готово за 327 мс, `me AHV15CAP`,
`land 9WrSXt7d_s3rYO543`, герой по D едет с 0 на 2. Мастер нужен только для того, чтобы комната
синхронизировалась со вторым окном.

## Цена выноса

Этот файл в CI не компилируется, поэтому переименование `$bog_gamengine_net_probe_no_master` или
`$bog_gamengine_net_probe_ok` сломает его молча, до первого ручного прогона. Вне тайпчека держатся
ровно два типизированных имени, оба перечислены выше. Тест в `net/probe/probe.node.test.ts`
сторожит их инвариант — что строки непустые и различные, — но НЕ свежесть этого файла: он живёт в
аудируемом модуле и о ссылках отсюда ничего не знает.

## Как прогнать руками

Мастер из корня MAM, отдельным терминалом:

```
sed -i '' 's/static masters() {/static masters() { return [];/' giper/baza/app/run/-/node.js
node ./giper/baza/app/run/-/node.js port=9090
```

Патч `masters()` обязателен: как есть бандл ходит на прод, а ленды пробы должны остаться
локальными (`<mam>/.baza`). Пересборка `node.js` патч затирает, повторять.

Затем сама проба:

```
node bog/gamengine/net/pair/-/node.test.js
```

Без мастера прогон печатает «мастер Базы на 9090 не слушает, проба пропущена» и остаётся
зелёным: здесь это честно, потому что прогон этого модуля никто не называет проверкой CI. Без
Chrome он краснеет, если объявлена переменная `CI` — решает `$bog_probe_done`.
