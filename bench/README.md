# $bog_gamengine_bench

Честный замер кадра: свой запуск Chrome с настоящим GPU и две страницы подряд в
одном браузере.

## Зачем отдельно от пробы

`bog/gamengine/probe` запускает Chrome с `--disable-gpu` и рисует через
SwiftShader, то есть растеризует на CPU. Для пикселей это ровно то, что нужно, для
замеров — нет: CPU-растеризатор платит за каждый отрезок и за каждый лишний квад, а
настоящий GPU не платит почти ничего. Поэтому **любая работа, перенесённая из DOM в
мир, на пробе выглядит дороже, чем она есть**, и решение «рисовать в мире или в DOM»
по её числам будет систематически неверным.

Замерено 25.09.2026 на одной и той же стратегии `bog/legion`, рамка выделения и
мини-карта в DOM против тех же линий в мире:

| где рисуется | Metal (этот модуль) | SwiftShader (проба) |
|---|---|---|
| DOM | 5.25 мс | 3.6 мс |
| мир | 5.23 мс | 5.7 мс |

На настоящем GPU разницы нет, на пробе мир «дороже в полтора раза». Числа пробы
здесь не ошибка измерения, а измерение не того.

## Как звать

```ts
$bog_gamengine_bench_say({
	root: '.',
	pages: [
		{ name: 'flat', page: 'bog/gamengine/demo/-/index.html#!demo=flat' },
		{ name: 'room', page: 'bog/gamengine/demo/-/index.html#!demo=room' },
	],
})
```

Печатает рендерер и таблицу медиан по кругам: `tick` из подвала страницы, главный
поток на кадр из счётчиков CDP, `layout` на кадр, число видов DOM.

По умолчанию три круга по 300 кадров, окно прогрева 180 кадров. Меняется
параметрами `laps`, `rounds`, `warm`. Страницы гоняются по очереди в одном процессе
браузера, круг за кругом: только так числа сравнимы, потому что загрузка машины за
время прогона плывёт.

Если рендерер оказался программным, перед таблицей печатается предупреждение, что
числа врут. Проверять его глазами обязательно: без настоящего GPU замер бессмысленен.

### Два варианта одного модуля

Сборка у модуля одна, поэтому A/B двух правок одного приложения делается копиями
сборки. `dir` подменяет странице `index.html` и `web.js`, всё остальное (атласы,
звуки) берётся из `root`:

```ts
pages: [
	{ name: 'dom', page: 'index.html', dir: '/tmp/build-dom' },
	{ name: 'world', page: 'index.html', dir: '/tmp/build-world' },
]
```

Собрать вариант, скопировать из `<модуль>/-/` файлы `index.html` и `web.js` в свою
папку, собрать второй, скопировать во вторую — и звать.

## В CI не включать

Это инструмент для руки, а не ворота. На раннере нет настоящего GPU, и замер там
даст ровно те числа, от которых этот модуль уводит. Ни один тест отсюда браузер не
поднимает: в ноде проверяются только сборка командной строки Chrome, разбор
счётчиков, медиана и маршрутизация статики.
