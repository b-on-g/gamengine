# Спайк 8.0. Rapier как планка для своего солвера

Страница `#!demo=rapier` (число ящиков в `#!demo=rapier/count=3000`): пол `Plane`
40×40, ящики `mesh` с `Box` падают решёткой 12×12 с высоты 5 слоями по 1.2, ходок
из комнаты, свет тот же. Физика `@dimforge/rapier3d-compat` 0.20.0: `World` с
гравитацией, `ColliderDesc.cuboid` на пол и на каждый ящик с `RigidBodyDesc.dynamic()`.
Узел-система `$bog_gamengine_spike_rapier_world` стоит первым в `kids` сцены, его
`step( dt )` копит `dt` и зовёт `world.step()` с `timestep` 1/60, не больше трёх
шагов на кадр, потом переписывает `pos` и `rot` мешей.

Замер пробой `spike/rapier/probe` на настоящем GPU (headless Chrome 153, Metal,
M4 Pro, 23.09.2026), три прогона на каждое число тел, подвал снимался каждые полсекунды
три секунды. `step` это одно `world.step()`, `copy` это перенос позиций и поворотов
в атомы, `тик` это главный поток от начала тика планировщика до конца `paint()`
(`draw.stat()`), `кадр` это интервал между кадрами.

| тел | step мс | copy мс | тик мс | кадр мс |
|---|---|---|---|---|
| 200 | 0.5–0.7 (пик 1.1–1.3) | 0.6 | 2.1–2.8 | 16.7 |
| 1 000 | 1.0–1.8 (пик 1.5–2.0) | 1.8–2.4 | 5.3–7.5 | 16.7 |
| 3 000 | 4.6–4.9 | 6.8–7.9 | 20.6–28.1 | 21–29 |

Пик это первые тридцать кадров: разогрев wasm и первое построение широкой фазы.
Через три секунды тысяча ящиков вся спит, `step` 0.15–0.25 мс, `copy` 0.2 мс.
Три тысячи за три секунды не засыпают, куча выше и дольше шевелится.

**Планка для этапа 8:** тысяча ящиков, шаг солвера не дольше 5 мс (втрое от 1.8).

Пол `step` при трёх тысячах это уже не физика: `copy` 7 мс плюс около 13 мс на
`world()` матрицы трёх тысяч холодных узлов в `batch.fill()`. Это цена атома на
каждый ящик, из архитектуры (раздел 1): при тысячах тел позиции должны жить в
буфере батча, а не в `pos` узла, независимо от того, чей солвер.

2 880 706 байт (2.75 МиБ), это вендоренный `rapier.js` с wasm в base64. Он же

## Как подключён пакет

`$node[ '@dimforge/rapier3d-compat' ]` в веб-бандле не работает. Сборщик берёт из
папки пакета только файлы корня с расширением `.js`, `package.json` с `main` не
читает, а у `rapier3d-compat` в корне нет ни одного js: всё в `dist/rapier.cjs`.
Расширение `.cjs` он тоже не считает скриптом. Поэтому `dist/rapier.cjs` скопирован
в `core/rapier.js` и переписан: снаружи обёртка

```js
var $node = $node || {}
$node[ '../bog/gamengine/spike/rapier/core/rapier' ] = ( function() { ... return rapier_out } )()
```

а внутри `exports` переименован в `rapier_out`. Переименование обязательно: тестовые
бандлы `*.test.js` склеивают файлы сырьём, без CommonJS-обёртки, и минифицированный
код объявлял `let $` на верхнем уровне, бандл падал с
`Identifier '$' has already been declared`. Убрать `exports.X =` нужно, чтобы
обёртка сборщика для обычных бандлов не сработала поверх своей: она бы записала
в `$node` пустой `module.exports`.

В нодовом бандле модуль `node` объявляет `$node` заново через `new Proxy`, и если
`core` встаёт в бандле раньше, регистрация теряется. Строка `const lib = $node`
в `core.ts` даёт зависимость на модуль `node`, и порядок становится верным.

`init()` один раз в мемо `rapier()`: `$mol_wire_sync( api ).init()`, мемо бросает
промис, `Draw` и подвал ждут, как ждут картинок. Инициализация 19 мс. Снаружи фибры
свежее чтение `sim()` бросает промис даже после `init()`, в скриптах пробы читать
через `$mol_wire_async`.

## Как копируется состояние

`bodies()` держит массив `RigidBody` в том же порядке, что меши. В `step` для каждого
тела `isSleeping()`, спящие пропускаются, для остальных `translation()` и
`rotation()`, кватернион в три угла Эйлера порядка `Rz · Ry · Rx` (как `node.trans()`)
помощником `$bog_gamengine_spike_rapier_world_euler`, тест в `world/world.test.ts`.
Записи `pos` и `rot` новыми `Float32Array`, иначе мемо матрицы не увидит смены.
Цена около 2 мкс на бодрствующее тело: `translation()` и `rotation()` в Rapier
создают объект на каждый вызов, плюс два `Float32Array` и две записи в атом.

## Грабли

- **Тело на кадр.** `bodies()` читало стартовые `pos()` мешей, а `step` их переписывал.
  Каждый кадр мемо инвалидировалось, создавало ещё тысячу тел в том же мире, `step`
  вырастал до 90–340 мс. Стартовые позиции теперь отдельный список `starts`, который
  никто не пишет. Симптом легко принять за медленный wasm: голый Rapier в той же
  вкладке давал 0.25 мс.
- `world()` у узла уже есть, это мировая матрица; мемо с миром физики зовётся `sim()`.
- В дереве `Box` был занят формой, `Box*` для мешей ломал сборку молча:
  «Need an equal default values». Меши называются `Crate*`.
- Проба на GPU: `--disable-gpu` вшит в `$bog_probe_browser`, `flags` только дописывает.
  На время пробы подменяется `child_process.spawn`, флаг вырезается, добавляется
  `--ignore-gpu-blocklist`. Рендерер в отчёте «ANGLE Metal Renderer: Apple M4 Pro».
- Накопитель `dt` ограничен тремя шагами на кадр, иначе при просадке кадра число
  шагов растёт вместе с кадром.
- `rm web.audit.js` без правки кода даёт 404 от дев-сервера, помогает `touch`
  любого исходника.
