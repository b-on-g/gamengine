# $bog_crumb2

Та же игра, что `bog/crumb`, но сцена собрана в редакторе `bog/gamestudio` мышью и
вывезена кнопкой «Вывезти дерево» двумя файлами: `level/level.view.tree` и
`level/level.view.ts`.

Играть: `bog/crumb2/app/-/index.html` через дев-сервер.

## Что откуда

| Часть | Откуда |
|---|---|
| карта 12 × 9 | размер и рисунок набраны текстом, одна стена поставлена кистью мышью |
| герой | класс «Ходок» из палитры, поставлен кликом по холсту |
| мир физики, плитка, атлас | палитра завела их сама вместе с героем |
| пять крошек | поставлены кликами по холсту |
| страница, HUD, камера, ввод, перезапуск | руками, `app/` |
| правила победы и таймер | руками, `rule/rule.ts` |

Вывезенный модуль правился руками в двух строках: `pos` героя вывозится
односторонним биндингом, а физическому телу нужен двусторонний.
