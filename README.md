# $bog_shooter_app

Шутер от первого лица на движке [`$bog_gamengine`](https://github.com/b-on-g/gamengine):
арена из символов в объёмном мире `phys3`, ходок с камерой на высоте глаз, выстрел лучом,
мишени, которые патрулируют и отстреливаются.

Играть: https://b-on-g.github.io/shooter/

## Управление

- `W` `A` `S` `D` и стрелки: ход.
- Пробел: прыжок.
- Мышь: поворот. Клик по холсту захватывает курсор, `Escape` отпускает.
- `Q` и `E`: поворот с клавиатуры, когда курсор не захвачен.
- `F` или клик: выстрел, очередью, пока клавиша зажата.

## Правила

- Мишень держит два попадания. На втором она становится телом физики, получает толчок
  и через две секунды исчезает.
- Мишень стоит на месте и стреляет, пока видит игрока лучом без препятствий, иначе
  ходит вдоль оси X и разворачивается у стены.
- Здоровье игрока в шапке. На нуле страница «Проиграл» с кнопкой «Ещё раз».
- Все мишени сняты — страница «Победил».

Карта лежит строкой в `app/app.view.tree`: `#` стена высотой 2, `.` пол, `E` мишень,
`P` старт. Арена 12 × 12 это 61 тело: плоскость пола, 56 стен-ящиков и 4 мишени.

## Из чего собрано

| Папка | Что |
| --- | --- |
| `app/` | страница игры, карта, батчи, свет, атлас и звуки |
| `arena/` | разбор карты из символов: стены, мишени, старт |
| `phys/` | мир `phys3` со слоем атласа на тело и замером шага |
| `player/` | ходок: мышь и клавиши, луч выстрела, здоровье |
| `target/` | мишень: патруль, луч видимости, стрельба, смерть телом |
| `gen/` | генератор картинок PNG и звуков WAV без внешних файлов |
| `probe/` | проба в Chrome: выстрел снимает мишень, `W` ведёт вперёд |

Картинки и звуки собирает `gen/`: `$bog_shooter_gen_run( root )` пишет четыре PNG 256 × 256
и два WAV в `app/atlas/` и `app/sound/`.

## Тени

Чекбокс «Тени» выключен по умолчанию: на SwiftShader в пробе второй проход съедает кадр.
На настоящем GPU его стоит включить.
