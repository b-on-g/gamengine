# $bog_gamengine_demo_jumper

Платформер на движке [`$bog_gamengine`](https://github.com/b-on-g/gamengine): вид сбоку,
уровень из символов, монеты, шипы, враги с машиной состояний, финишный флаг.

Играть: https://b-on-g.github.io/gamengine/#!demo=jumper

## Управление

- `A` и `←` влево, `D` и `→` вправо.
- `W`, `↑` и пробел прыжок, только с земли.
- На телефоне джойстик и кнопка «Прыжок»; на десктопе они включаются чекбоксом «Кнопки».

## Правила

- Монета даёт очко, шип отнимает жизнь и возвращает на старт.
- Прыжок сверху убивает врага, касание сбоку отнимает жизнь.
- Флаг это финиш: страница победы с кнопкой «Ещё раз». Жизни кончились — та же страница.

## Из чего собрано

| Папка | Что |
| --- | --- |
| `jumper.view.tree` | страница игры, карта уровня, атлас, звуки |
| `level/` | разбор карты из символов: тайлы, монеты, шипы, враги, старт |
| `hero/` | герой: гравитация, прыжок с земли, жизни, подбор предметов |
| `enemy/` | враг: ходьба по платформе, разворот у края через `brain/fsm` |
| `item/` | монета, шип и флаг как `ghost` тела физики |
| `probe/` | проба в Chrome: прыжок, ход вправо, подбор монеты, кадр не чёрный |
| `look/` | подпись картинки: медиана, тени, точки неба, земли и героя |

Карта уровня лежит строкой в `jumper.view.tree`: `#` земля, `=` платформа,
`o` монета, `x` шип, `E` враг, `F` финиш.
