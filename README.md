# $bog_crumb

Маленькая игра на `bog/gamengine`: герой ходит по лабиринту на WASD и собирает пять
крошек за сорок секунд. Собрал все — победа, кончилось время — проигрыш.

Играть: `bog/crumb/app/-/index.html` через дев-сервер.

## Зачем она

Это проверка редактора `bog/gamestudio`, а не игра ради игры. Три предыдущие игры
написаны кодом, и каждая дала движку список недостающего. Через редактор не сделано
ещё ни одной, поэтому сцена этой игры собрана мышью в редакторе, а всё, чего редактор
не умеет, дописано руками. Что именно пришлось дописать, записано в отчёте задачи 6.23
плана движка.

## Что откуда

| Часть | Откуда |
|---|---|
| карта 12 × 9 | набрана в редакторе: кистью по холсту и правкой во вкладке «Исходник» |
| позиции героя и пяти крошек | расставлены кликами по холсту в редакторе |
| столкновения со стенами | руками: `phys` с `phys_tile`, герой это `phys_body` |
| правило победы и таймер | руками: `rule/rule.ts` |
| ввод, камера, HUD, страница | руками: `app/` |

Из документа редактора в игру переехали девять строк карты и шесть пар координат.
Остальное переписано: редактор кладёт позицию списком (`pos / 1.5 -1.5 0`), а такой
литерал не проходит сборку MAM, и классы редактора (`$bog_gamestudio_sample_map`,
`$bog_gamestudio_sample_hero`) в игру не годятся.

## Из чего собрано

| Папка | Что |
|---|---|
| `app/` | страница игры, карта, сцена, физика, камера, HUD, итог |
| `hero/` | герой: тело физики, скорость по осям ввода |
| `rule/` | правило: сбор крошек по радиусу, счёт, таймер, победа и проигрыш |

Крошка не удаляется из сцены, а прячется флагом `hidden` узла движка: массивы узлов и
батчи при сборе не пересобираются.
