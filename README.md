# $bog_legion_app

Стратегия с видом сверху на движке [`$bog_gamengine`](https://github.com/b-on-g/gamengine):
карта 40 × 30 из символов одним тайлмапом, сто юнитов, у каждого навигация по сетке и
своя голова, рамка выделения, приказы толпой, мини-карта.

Играть: https://b-on-g.github.io/legion/

## Управление

- Мышь у края холста: прокрутка камеры. Колесо: приближение.
- Левая кнопка: рамка выделения своих. Короткий клик выделяет одного.
- Правая кнопка: приказ выбранным идти в точку, цели раскладываются сеткой вокруг неё.
- Пробел: пауза. `Escape`: снять выделение.

## Правила

- Два лагеря по 50 юнитов. Свои синие, враги красные, выбранные подсвечены.
- Юнит видит врага на 7 метров и атакует с 1.2 метра раз в 0.7 секунды.
- Здоровье 40, урон 7. На нуле юнит исчезает, на его месте вспышка частиц.
- Свои ходят по приказу, враги патрулируют вокруг своей базы и бросаются на замеченного.
- Лагерь уничтожен — страница итога с кнопкой «Ещё раз».

Карта лежит строкой в `app/app.view.tree`: `#` стена, `.` пол, `A` и `B` базы, `o` ресурс.

## Из чего собрано

| Папка | Что |
| --- | --- |
| `app/` | страница игры, карта, узлы, батчи, выделение, приказы, HUD и мини-карта |
| `unit/` | юнит: агент навигации, поиск врага, атака по таймеру, патруль, смерть |
| `act/` | лист дерева поведения, ставящий юниту режим |
| `probe/` | проба в Chrome: сто юнитов, рамка, приказ, цена кадра |

Свои думают машиной состояний `brain/fsm` (`idle → move → attack → dead`), враги тем же
набором условий через дерево поведения `brain/bt`. Условия это методы юнита: `has_foe`,
`in_reach`, `busy`, `resting`, `lost_foe`.

## Цена кадра

Проба на SwiftShader со ста юнитами показывает `tick` около 3.8 мс при потолке 8 мс.
Юниты, спрайты и мозги это 911 холодных узлов сцены при потолке зоны около 10 000.

Мини-карта обновляется раз в полсекунды от `$mol_state_time.now( 500 )`, а не каждый
кадр: сто точек в DOM на 60 Гц стоят дороже самой игры.
