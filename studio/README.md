# $bog_gamengine_studio

Редактор сцен для `bog/gamengine`, страница демо `#!demo=studio`. Документ сцены это текст `view.tree`, редактор компилирует его штатным компилятором мола прямо в браузере через `new Function`, поэтому странице нужен `unsafe-eval`: `demo/index.html` без `Content-Security-Policy`, а на своём хостинге в `script-src` добавляйте `'unsafe-eval'`.

Над холстом кнопки «Играть», «Пауза», «Стоп». В режиме правки часы стоят, работают гизмо и инспектор. «Играть» снимает снимок всех свойств узлов через `props()`, запускает часы и включает ввод: герой образца (`$bog_gamengine_studio_sample_hero`) ходит по WASD. «Стоп» останавливает часы и возвращает узлам значения из снимка, исходник при этом не меняется. Узлы, созданные или удалённые во время игры, откат не трогает. Правка исходника во время игры пересобирает сцену заново, состояние игры теряется.

Список ассетов панели лежит в `assets/assets.json` и собирается из `deploy` всех `*.meta.tree` пака движка: `node bog/gamengine/pack/-/node.js assets bog/gamengine/demo bog/gamengine/studio/assets/assets.json`. Обновляйте его после добавления картинок, моделей и звуков в `bog/gamengine/demo`, а сами файлы добавляйте в `deploy` в `demo/demo.meta.tree`, иначе страница их не отдаст. Если файла нет, панель берёт список из `fallback` в `studio.view.tree`.
