# $bog_gamengine_studio_pair

Парный сценарий редактора: два редактора на одном ленде, правка первого видна второму за 500 мс.
Лежит отдельным модулем и **в списке `modules:` рабочего потока не стоит намеренно.**

Имя каталога `pair`, а не `live`: путь `studio/probe/live` складывался бы из имени
`$bog_gamengine_studio_probe_live`, которое уже носит функция сценария, и разрешитель имён MAM
превратил бы ссылку на функцию в ссылку на модуль — тест уехал бы в бандл родителя и остался бы в
прогоне CI. Проверено: с каталогом `live` имя теста находилось в `studio/probe/-/node.test.js`, с
`pair` вхождений ноль.

## Почему не в CI

Пробе нужен мастер Гипер Базы на 9090, и на раннере его нет. Если оставить проверку в прогоне,
её пропуск («мастер Базы на 9090 не слушает») становится успехом, и CI отчитывается о проверке
совместной правки, не сделав её. Красным навсегда делать тоже нельзя: `$mol_test` встаёт на
первом падении, поэтому вечно красная проба заслонила бы любой настоящий красный после себя.

Пропуск бывает двух родов, и это второй: **условие не непреодолимое, а недостающее** — мастера
можно поднять. Такое обещание из прогона вынимают, а не объявляют приемлемым, поэтому здесь и
модуль, и эта страница.

Проверяемая половина сценария из прогона НЕ ушла: `$bog_gamengine_studio_probe_alone` в
родительском модуле поднимает один редактор с `master=` в адресе и утверждает, что он вышел на
свой ленд и показал документ. Мастера ей не нужно — замерено 25.09.2026: без мастера редактор
готов за 440 мс, `me QST9I8IZ`, `land SX0gSljh_JMcbn38K`, `mates 0`, исходник 953 знака. Мастер
нужен только для синхронизации, а не для появления ленда.

## Цена выноса

Этот файл в CI не компилируется, поэтому переименование `$bog_gamengine_studio_probe_no_master`
или `$bog_gamengine_studio_probe_live_ok` сломает его молча, до первого ручного прогона. Вне
тайпчека держатся ровно два типизированных имени, оба названы здесь; своих имён у модуля нет, и
сценарий он адресует строками, которые не сторожатся нигде и никогда.

Тест `skipping the live scenario, passing it and coming up alone are three different sayings` в
`studio/probe/probe.node.test.ts` сторожит инвариант этих строк — что они непустые и различные, —
но **не свежесть этого файла**: он живёт в аудируемом модуле и о ссылках отсюда ничего не знает.
Инвариант ценен сам по себе, потому что до него «пропуск и успех не одно значение» держалось
только словами.

## Как прогнать руками

Мастер из корня MAM, отдельным терминалом:

```
sed -i '' 's/static masters() {/static masters() { return [];/' giper/baza/app/run/-/node.js
node ./giper/baza/app/run/-/node.js port=9090
```

Патч `masters()` обязателен: как есть бандл ходит на прод, а ленды пробы должны остаться
локальными (`<mam>/.baza`). Пересборка `node.js` патч затирает, повторять.

Затем сама проба:

```
node bog/gamengine/studio/pair/-/node.test.js
```

Без мастера прогон печатает «мастер Базы на 9090 не слушает, проба пропущена» и остаётся
зелёным: здесь это честно, потому что прогон этого модуля никто не называет проверкой CI.
Без Chrome он краснеет, если объявлена переменная `CI` — решает `$bog_probe_done`.
